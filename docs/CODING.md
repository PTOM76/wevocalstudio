# コーディング規約
WeVocalSynth の docs/CODING.md と同じ決まりを使う。ここには Studio だけのことを書く。

関連: [アーキテクチャ](ARCHITECTURE.md)

## 大きさ
- 1 ファイル 300 行を目安とし、500 行を上限とする

## コメント
- ファイルの 1 行目に、何をするファイルかを 1 行で書く
- コメントは日本語で書く。識別子は英語のまま
- 何をしているかより、なぜそうしているかを書く

## TypeScript / React
- 音声は `Clip` で扱い、`AudioBuffer` は再生の直前にだけ作る（`engine.ts`）
- 元の音（`Source` の `Clip`）は書き換えない。変えるのは波形ブロックの値だけ
- 時間は秒で持つ。サンプルに直すのは処理の入口だけ
- 表示する文言は `t()` / `useT()` を通す。新しい文言は `src/lang/` のすべての言語に足す（キーは `領域.名前`）
- MUI の配置は `sx` に書く（v9 では `alignItems` などの props が廃止）
- `App.tsx` は画面の組み立てだけにし、状態と操作はフック（`useProject.ts`）に置く

## コミット
- メッセージは `feat:` / `fix:` / `refactor:` / `chore:` と日本語の要約。本文に変更の理由を書く
- 1 つの機能、修正ごとにコミットする。変更したファイルを指定して `git add` する
