# 要件定義
WeVocal Studio が何を目指し、どこまでできているか。残っている作業はルートの `TASK.md` にある。(2026-10-24 時点)

関連: [アーキテクチャ](ARCHITECTURE.md)、[決定事項](DECISIONS.md)

## 概要
ブラウザ上で、トラックに音声と MIDI をブロックとして並べて編集する DAW。WeVocalSynth の音声加工（ピッチ、伸縮、フォルマント）を、複数のトラックと波形ブロックで使用できるようにする。

## 方針

| 方針 | 理由 |
| --- | --- |
| インストール不要で、ブラウザだけで動く（PWA） | 気軽に試せることを優先するため。ブラウザで足りない所（VST など）は、ネイティブ版（Tauri が第一候補）を別に検討する |
| 音声ファイルをサーバーへ送らない | 音声の権利やプライバシーを気にせず使用できるようにするため。自動保存もブラウザ内（IndexedDB）か、利用者が選んだフォルダーに限る |
| 元の音を書き換えない | 波形ブロックの値をあとから何度でも変えられるようにするため（[アーキテクチャ](ARCHITECTURE.md)の「原音から作る」） |
| WeVocalSynth と同じ処理、同じ部品、同じ設定 | Synth と行き来しても同じ音、同じ操作になるようにするため。Synth と Analyzer にある機能は Studio にもそろえる |
| パソコンとスマホの両方で使用できる | 画面の大きさに合わせて置き方を変える（スマホは編集バー、長押しのメニュー） |

## 機能

### できていること
ルートの README.md の「できること」と、[バージョン履歴](VERSION.md)にある。

| 分類 | 主なもの |
| --- | --- |
| 配置と編集 | 波形ブロックの移動、分割、複製、フェード、範囲の操作、スナップ、マーカー、元に戻す、操作履歴 |
| 波形ブロック | 音量、ピッチ、速度、フォルマント、処理方式、ピッチカーブ、音量とピッチのエンベロープ、逆再生、確定 |
| トラック | 音量、パン、ミュート、ソロ、位相の反転、サブトラック、FX の列、センド、オートメーション、フリーズ |
| MIDI | MIDI ブロック、ピアノロール、音源（シンセ、サンプラー）、MIDI ファイルの読み込みと書き出し |
| 保存と書き出し | .wvst、自動保存と復元、プロジェクトのタブ、WAV / FLAC / MP3 / Opus / AAC、動画、WeVocalSynth のプロジェクト |
| 追加機能 | ボーカル抽出、解析の欄（スペクトログラム、F0）、動画の書き出し |

### 試験的なもの
| 機能 | 状態 |
| --- | --- |
| VST プラグイン | wevocal-vstbridge（x86 と x64 のエミュレーターを Rust から wasm にしたもの）で、VST2 の一部が動く。VST3 と 64 ビットの画面は未対応 |
| 和音の分離、GPU での加工 | 試験的機能として使用できる |
