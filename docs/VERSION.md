# バージョン履歴
マイナーバージョンごとの主な変更。細かい修正は省く。

## v0.0 (0.0.1)
2026-10-09〜

試験版。MVP（基本操作、再生、編集、書き出し）。画面の操作は REAPER にそろえる。

### 配置と編集
- 起動したときに空のトラックを 1 つ用意する。音声ファイルを読み込むと、空いているトラックか新しいトラックに波形ブロックとして置く。トラックの上にドロップすると、その位置に置く
- 波形ブロックをドラッグで動かす（ほかのトラックへも移せる。重ねて置け、重なった所は REAPER と同じく段に分けて表示する）。端をドラッグで長さ、上の角をドラッグでフェード
- 範囲選択（トラックの空いている所をドラッグ。Esc で解除）。目盛りの上をドラッグすると再生位置が付いてくる（WeVocalSynth と同じ）
- テンポ（BPM、拍子。再生のバーで変える）。目盛りに小節の番号、線は拍と小節（「表示」と設定で秒にも切り替える）。スナップも拍に寄せる。範囲の両端で分割（Shift+S）
- 分割（S）、削除（Delete）、コピー（Ctrl+C）、貼り付け（Ctrl+V。選んでいるトラックの再生位置）、複製（Ctrl+D）
- 複数選択（Ctrl を押しながらクリック、Ctrl+A ですべて）。移動、削除、ピッチ、コピー、複製は選んだもの全部に掛ける
- スナップ（目盛りの線、波形ブロックの端、再生位置。Shift を押しながらドラッグで外す。Alt+S と「表示」で切り替え）
- 元に戻す（Ctrl+Z）、やり直す（Ctrl+Shift+Z、Ctrl+Y）。ドラッグとスライダーは 1 回分にまとめる

### マーカー
- マーカー（M で再生位置に足す、] と [ で次と前へ。目盛りの上でダブルクリックして名前の変更と削除。WeVocalSynth と同じ形）

### 波形ブロック
- フォルマントのずらし量（半音。Synth と同じ処理。プロパティで指定）
- 新しい波形ブロックと分割した切れ目には 10ms のフェードを付ける（REAPER の既定と同じ。プツッという音を防ぐ）
- 右クリックのメニューと F2 で「プロパティ」を開き、位置、長さ、元の音の開始位置、音量、ピッチ、処理方式、フォルマント、フェード、ミュートを数値で指定する
- ピッチは WeVocalSynth と同じ処理方式で元の音から作る。処理方式とフォルマントは波形ブロックごとに持つ（設定の「ピッチ」は新しい波形ブロックの既定値）。作ったものはキャッシュし、できるまでは元の音で鳴らす
- ピッチのキー: Shift+0 と Shift+9（REAPER と同じ）、テンキーの 9 と 3 で 1 半音。テンキーで Shift を足すと 10 セント。Ctrl+↑↓ でも変えられる。Ctrl+Backspace か Ctrl+0 で元に戻す

- 速度（REAPER のアイテムの再生速度。ピッチは変えずに長さが変わる。1/4〜4 倍）。プロパティで指定するか、Alt を押しながら端をドラッグ。処理は Synth と同じ伸縮で、できるまでは元の音を速く鳴らす

### トラック
- トラックごとの音量、パン、ミュート、ソロ。名前はダブルクリックで変える。トラックの追加と削除
- マスタートラック（一番上。音量、パン、ミュート）

### 録音
- 録音（再生のバーの ● か Ctrl+R）。再生位置から、ほかのトラックを鳴らしながら録る。トラックの ● で録音待機（なければ選んでいるトラックか空いているトラック）。録った音は録り始めた位置の波形ブロックになる
- 入力元は設定の「録音」で選ぶ。ブラウザによる音の加工（エコー除去など）は切る

### 再生と書き出し
- 再生のボタン一式（先頭へ、停止、再生と一時停止、録音、リピート、末尾へ）を時間軸の下に置く。再生のボタンは再生と一時停止の切り替え（Synth と同じ）。停止は再生を始めた位置（再生中に動かしたらその位置）に戻る。目盛りのドラッグで端に来たら表示を流し、再生中は表示が再生位置に付いていく。範囲選択があれば範囲の中だけを鳴らし、リピートでくり返す
- キーの割り当ては設定の「キーとマウス」で変えられる（PevenMUI の KeymapEditor。WeVocalSynth と同じ）
- キー: Space で再生と停止、Ctrl+Space で一時停止、R でリピート、Home と End、テンキーの + と - で拡大と縮小
- 書き出し（Ctrl+Alt+R）: WAV、FLAC、MP3、AAC、Opus。範囲選択の所だけも書き出せる
- プロジェクトの保存（Ctrl+S、.wvstudio）と開く（Ctrl+O）
- PWA（インストールしてオフラインでも使える。新しい版は「更新」を押したときに切り替える）。アイコンはクモの巣に波形
- 作業を自動保存し（IndexedDB）、次に開いたときに復元する（WeVocalSynth と同じ。設定の「全般」で切り替え）
