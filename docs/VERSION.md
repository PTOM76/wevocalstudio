## v0.0 (0.0.1)
2026-10-09〜

試験版。

- 音声ファイルを読み込み、ファイルごとのトラックに波形ブロックとして並べる（ドロップでも読み込める）
- 波形ブロックをドラッグで動かす。ほかのトラックへも移せる。再生位置で分割（S）、削除（Delete）
- 波形ブロックごとの音量、フェードイン、フェードアウト、ミュート。ピッチ（半音）は WeVocalSynth と同じ処理方式で元の音から作る（設定の「ピッチ」で方式とフォルマントを選ぶ。作ったものはキャッシュし、できるまでは元の音で鳴らす）
- トラックごとの音量、パン、ミュート、ソロ
- 再生、停止（Space）、全トラックを混ぜて WAV で書き出す
