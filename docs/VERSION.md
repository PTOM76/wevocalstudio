# バージョン履歴
マイナーバージョンごとの主な変更。細かい修正は省く。

## v0.0 (0.0.1)
2026-10-09〜

試験版。MVP（基本操作、再生、編集、書き出し）。画面の操作は REAPER にそろえる。

### 配置と編集
- 起動したときに空のトラックを 1 つ用意する。音声ファイルを読み込むと、空いているトラックか新しいトラックに波形ブロックとして置く。トラックの上にドロップすると、その位置に置く
- 波形ブロックをドラッグで動かす（ほかのトラックへも移せる。重ねて置け、重なった所は REAPER と同じく段に分けて表示する）。端をドラッグで長さ、上の角をドラッグでフェード
- 範囲選択（トラックの空いている所をドラッグ。Esc で解除）。目盛りの上をドラッグすると再生位置が付いてくる（WeVocalSynth と同じ）
- グリッドの細かさ（1/1〜1/256 音符。再生のバーで数字を入れる。3 や 6 で 3 連符）。拍より細かい線は薄く出し、スナップと編集カーソルもこれに合わせる
- テンポ（BPM、拍子。再生のバーで変える。「再生」→「テンポを解析」で、選んだ波形ブロックから BPM と 1 拍目を求める。WeVocalSynth と同じ解析）。目盛りに小節の番号、線は拍と小節（「表示」と設定で秒にも切り替える）。スナップも拍に寄せる。範囲の両端で分割（Shift+S）
- 無音で区切る（「編集」。音のある所だけを残す。-40dB、200ms。WeVocalSynth と同じ判定を wevocal-lib に移して使う）
- Alt を押しながら本体をドラッグすると、位置と長さはそのままで中の音だけをずらす（REAPER のスリップ編集）
- 選択も元に戻せる（REAPER の「選択も元に戻す」と同じ。枠でのドラッグは 1 回分）
- Ctrl を押しながらドラッグすると複製（写しをその場に残す。REAPER と同じ）。動かさずに離せば選択の足し引き
- トラックの欄を押して Ctrl+C、Ctrl+V で、トラックを波形ブロックごとすぐ下に貼り付ける
- スナップが入っていれば、編集カーソルと範囲選択の端はいちばん近いグリッドの線に合わせる（Shift で外す）
- 何もない所の右クリックのメニュー（トラックの空いている所: ここに貼り付け、ここに読み込む、すべて選択、範囲の操作、トラックの追加。目盛りの上: ここにマーカー、テンポの解析）
- 波形ブロックを押すと、押した所（端ならその端）に再生位置を移す（REAPER と同じ）
- 分割（S）、削除（Delete）、切り取り（Ctrl+X）、コピー（Ctrl+C）、貼り付け（Ctrl+V。選んでいるトラックの再生位置に置き、貼り付けたものの右端へ再生位置を移すので、続けて押すとすき間なく並ぶ）、複製（Ctrl+D）
- 複数選択（Ctrl+クリックで足し引き、Shift+クリックで起点からの範囲、右ドラッグの枠、Ctrl+A ですべて）。移動、削除、ピッチ、コピー、複製は選んだもの全部に掛ける
- スナップ（目盛りの線、波形ブロックの端、再生位置。Shift を押しながらドラッグで外す。Alt+S と「表示」で切り替え）
- 操作履歴の一覧（「編集」。押した所まで戻る、進む。WeVocalSynth と同じ）
- 元に戻す（Ctrl+Z）、やり直す（Ctrl+Shift+Z、Ctrl+Y）。ドラッグとスライダーは 1 回分にまとめる

### マーカー
- マーカー（M で再生位置に足す、] と [ で次と前へ。目盛りの上でダブルクリックして名前の変更と削除。WeVocalSynth と同じ形）

### 波形ブロック
- フォルマントのずらし量（半音。Synth と同じ処理。プロパティで指定）
- 音量のエンベロープ（REAPER のアイテムの音量エンベロープ。ツールバーか E で出し、線を押して点を足す、ドラッグで動かす、ダブルクリックで消す。点の間は dB でまっすぐ）
- 新しい波形ブロックと分割した切れ目には 10ms のフェードを付ける（REAPER の既定と同じ。プツッという音を防ぐ）
- 右クリックのメニュー、ダブルクリック、F2 で「プロパティ」を開き（複数を選んでいれば一括。変えた欄だけを全部に掛ける）、元の音（ファイルからも）、位置、長さ、元の音の開始位置、音量、ピッチ、処理方式、フォルマント、フェード、ミュートを数値で指定する
- ピッチは WeVocalSynth と同じ処理方式で元の音から作る。処理方式とフォルマントは波形ブロックごとに持つ（設定の「ピッチ」は新しい波形ブロックの既定値）。作ったものはキャッシュし、できるまでは元の音で鳴らす
- ピッチは ±256 半音まで（24 半音を超える分は、wasm が長さを変えずに何回かに分けて処理する。上げる処理の途中で音が長くなりすぎないように）
- ピッチのキー: Shift+0 と Shift+9（REAPER と同じ）、テンキーの 9 と 3 で 1 半音。テンキーで Shift を足すと 10 セント。Ctrl+↑↓ でも変えられる。Ctrl+Backspace か Ctrl+0 で元に戻す

- 速度（REAPER のアイテムの再生速度。ピッチは変えずに長さが変わる。1/4〜4 倍）。プロパティで指定するか、Alt を押しながら端をドラッグ。処理は Synth と同じ伸縮で、できるまでは元の音を速く鳴らす

### トラック
- トラックの複数選択（Ctrl+クリック、Shift+クリック）。選んだトラックの一つで音量やパンを動かすと全部が同じだけ動く（REAPER と同じく差分で）。ミュートやソロも全部に掛ける
- トラックとマスターの音量は、レベルメーターを溝にした音量のつまみ（右に dB）。パンは真ん中から色が伸びる棒（右に C、L30、R30）。どちらもダブルクリックで戻す
- レベルメーター（トラックとマスターの音量のつまみの中、再生のバーの時間の横。WeVocalSynth と同じ wevocal-lib の LevelMeter。「表示」で切り替え）
- トラックの欄のボタン（●、M、S、Ø、EQ）は WeVocalSynth と同じ見た目（入っているときだけ色で塗る。M は橙、S は緑、● は赤）。選んでいるトラックは左端に色の帯、鳴らないトラックの波形は薄く出す
- トラックごとの音量、パン、ミュート、ソロ。名前はダブルクリックで変える。トラックの欄の右クリックで名前の変更、複製、削除
- 位相の反転（Ø。WeVocalSynth のフェーダーと同じ）
- トラックのグラフィック EQ（WeVocalSynth と同じ。10 帯と 31 帯、±12 dB と ±24 dB。トラックの「EQ」から）。計算とグラフは wevocal-lib に移して共通にした
- マスタートラック（一番上。音量、パン、ミュート）

### 表示
- ステータスバーを WeVocalSynth と同じ並びにする（プロジェクト名と保存していない印、形式、範囲選択（押すと数字で）、BPM、処理中のゲージ。ゲージは PevenMUI の JobGauge）
- メニューの下のツールバー（WeVocalSynth と同じ形。切り取り、コピー、貼り付け、再生位置に追従、スナップ、拡大と縮小）。追従は F で切り替え、切ると再生中も表示が動かない
- ミニマップ（全体を縮めた波形。今の表示範囲を枠で示し、ドラッグで移動。WeVocalSynth と同じ部品。「表示」で切り替え）

- ピッチカーブ（解析の欄の「ペン」でなぞった高さになる。Alt で消す。元の F0 は薄い線、変えたあとは水色の線。WeVocalSynth と同じ wevocal-lib の curve で、元の音から作る）
- 解析の欄（WeVocalAnalyzer のスペクトログラムと F0 の線。選んだ波形ブロックの音を時間軸とそろえて描く。マウスの位置の周波数と音名。「表示」で切り替え）

### 録音
- 録音（再生のバーの ● か Ctrl+R）。再生位置から、ほかのトラックを鳴らしながら録る。トラックの ● で録音待機（なければ選んでいるトラックか空いているトラック）。録った音は録り始めた位置の波形ブロックになる
- 入力元は設定の「録音」で選ぶ。ブラウザによる音の加工（エコー除去など）は切る

### 再生と書き出し
- 編集カーソル（赤。押した所、貼り付ける所。再生では動かない）と再生カーソルを分ける（REAPER と同じ）。停止で再生カーソルは消え、次の再生は編集カーソルから。一時停止はその場に残し、続きから鳴らす
- 曲の終わり（最後の波形ブロックの終わり）に線を出し、そこで再生を止める
- 再生中に変えたものは、その波形ブロックだけを差し替える（音量、パン、ミュート、ソロ、EQ は鳴らしたまま変える）。貼り付けても再生が止まらない
- 再生のボタン一式（先頭へ、停止、再生と一時停止、録音、リピート、末尾へ）を時間軸の下に置く。再生のボタンは再生と一時停止の切り替え（Synth と同じ）。停止は再生を始めた位置（再生中に動かしたらその位置）に戻る。目盛りのドラッグで端に来たら表示を流し、再生中は表示が再生位置に付いていく。範囲選択があれば範囲の中だけを鳴らし、リピートでくり返す
- キーの割り当ては設定の「キーとマウス」で変えられる（PevenMUI の KeymapEditor。WeVocalSynth と同じ）
- ← → で再生位置を 1 拍ずつ、テンキーの 4 と 6 で選んだ波形ブロックを 1 拍ずつ動かす（REAPER と同じ）。Ctrl+N で新しいプロジェクト
- キー: Space で再生と停止、Ctrl+Space で一時停止、R でリピート、Home と End、テンキーの + と - で拡大と縮小
- 書き出し（Ctrl+Alt+R）: WAV、FLAC、MP3、AAC、Opus。範囲選択の所だけも書き出せる
- プロジェクトの保存（Ctrl+S、.wvstudio）と開く（Ctrl+O）
- PWA（インストールしてオフラインでも使える。新しい版は「更新」を押したときに切り替える）。アイコンはクモの巣に波形
- 作業を自動保存し（IndexedDB）、次に開いたときに復元する（WeVocalSynth と同じ。設定の「全般」で切り替え）
