# 画面
パソコンとスマホの画面の各部の名前と役割。

## パソコン

| 場所 | 内容 |
| --- | --- |
| 上部のバー | メニュー、プロジェクト名、元に戻す、やり直し |
| ツールバー | 切り取り、コピー、貼り付け、再生位置に追従、スナップ、拡大と縮小など |
| 時間目盛り | 小節の番号（または秒）。クリックやドラッグで再生位置を移動する |
| トラックの欄（左） | トラックの名前、録音待機（●）、ミュート（M）、ソロ（S）、位相の反転（Ø）、FX、音量、パン |
| 時間軸（右） | 波形ブロックを並べる。範囲の選択、編集カーソルの移動もここで行う |
| 解析の欄 | スペクトログラムとピッチ（F0）の線。「表示」で切り替える（[解析の欄](tools.md#解析の欄)） |
| ミニマップ | 全体を縮小した波形。枠が現在の表示範囲で、ドラッグで移動する |
| 再生のバー | 先頭へ、停止、再生と一時停止、録音、リピート、末尾へ。時間、レベルメーター、テンポ、グリッド |
| ステータスバー | プロジェクト名、形式、範囲、BPM、処理の進み具合 |

| メニュー | 主な項目 |
| --- | --- |
| ファイル | 開く、最近使用したファイル、プロジェクトを保存、名前を付けて保存、最適化して保存、音声ファイルを読み込む、書き出す、フォルダーへ保存、新しいウィンドウ、設定 |
| 編集 | 元に戻す、やり直す、操作履歴、切り取り、コピー、貼り付け、複製、すべて選択、分割、無音で区切る、削除、範囲の操作、マーカー |
| 波形ブロック | プロパティ、ピッチの上げ下げ、ノーマライズ、確定、ボーカル抽出 |
| トラック | トラックを追加、複製、名前の変更、サブトラックを追加、削除、ミュート、ソロ |
| ツール | 音声を作成、MIDI の音符に並べる、一音ずつ切り出す、ボーカル抽出 |
| 再生 | 再生、一時停止、範囲を再生、録音、リピート、先頭と末尾へ、テンポを解析、マーカー |
| 表示 | 拡大、縮小、全体を表示、範囲に合わせて拡大、スナップ、再生位置に追従、エンベロープ、拍と小節で表示、解析の欄、レベルメーター、ミニマップ、ステータスバー |
| ヘルプ | 使い方、ショートカット一覧、更新を確認、ライセンス、このアプリについて |

メニューのキーの割り当ては、メニューの右側に表示される。

## スマホ

- メニューは上部のバーの ⋮ にまとめられている
- トラックの欄は狭くなり、入りきらない再生のバーの項目は ▼ にしまわれる。目盛りの左の « を押すと、トラックの欄を閉じて時間軸を広く使用できる（» で開く。縦持ちの画面向け。閉じたかどうかは次回も引き継がれる）
- 波形ブロックか範囲を選択すると、画面の下に編集バーが表示される（[編集バー](blocks.md#編集バー)）
- 波形ブロックをダブルタップするとプロパティ、長押しするとメニューを開く
- MIDI ブロックは、指でつかんで動かし（縦に動かすとほかのトラックへも移る）、両端をつかんで長さを変えられる（端をつかめる幅は広い）。ダブルタップでピアノロールを開き、長押しすると MIDI ブロックのメニュー（プロパティ、ピアノロール、音源、切り取り、コピー、複製、分割、削除、つなぐ、書き出し）を開く。選ぶと、画面の下の編集バーにも、ピアノロール、音源、つなぐなどのボタンが出る
- 何もない所を長押ししてそのままなぞると、範囲を選択できる（動かさずに指を離すと、その場所のメニューが開く）
- 2 本指のピンチで拡大と縮小、なぞると横にスクロールする
- トラックの欄を長押しすると、トラックのメニューを開く
- ピアノロールは、画面いっぱいに開く。選択の道具で、空いている所を指でなぞるとスクロールし、押して離すと音符が足され、長押ししてなぞると枠で選択できる（ペンの道具では、押すと音符が足される）。2 本指のつまみで拡大と縮小、なぞるとスクロールする。音符を長押しすると、削除、コピー、複製のメニューが開く。音符の右端をつかめる幅と、行の高さは、指で操作しやすいよう広い
- iPhone、iPad は、マナーモードでも音が鳴るように再生用の音声セッションに切り替える
