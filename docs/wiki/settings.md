# 設定
設定画面の各項目。

「ファイル」→「設定…」で開く。パソコンでは別のウィンドウで開く。

| 分類 | 内容 |
| --- | --- |
| 全般 | 自動保存と復元、閉じる前の確認、ウィンドウの数、音声の出力先と上限（リミッター）、録音の入力元とブラウザの音声処理、元に戻せる回数、最近使用したファイル、保存先のフォルダー |
| 編集 | グリッド、スナップ、貼り付けと無音の挿入のあとの再生位置などの編集の動作 |
| キーとマウス | Ctrl+S の動作（保存か書き出し）、ホイールでの拡大縮小の操作、キーの割り当て（操作ごとに複数のキーを割り当てられる） |
| ファイル | ファイルの読み込みと保存の動作 |
| 表示 | テーマ、画面の拡大率、編集バーの表示、レベルメーター、ミニマップの再生位置、言語 |
| ピッチ | 新しい波形ブロックの処理方式とフォルマントの既定値、先に計算して鳴らす設定、テンポの自動解析と新しいプロジェクトの BPM、解析の欄の音の範囲、「平らにする」の強さ |
| ボーカル抽出 | モデル、GPU、高域の保持、CPU のスレッド数とメモリの上限、楽器ごとの分離のモデル、ボーカルの主旋律とハモリへの分離 |
| データ | 追加機能の導入と削除、保存されているデータ |
| 開発者向け | デバッグ表示、開発版の更新の受け取り、停止中の音声処理の一時停止、iPhone と iPad の消音スイッチでの再生、ファイルの選択方法、ダイアログの表示方法 |
