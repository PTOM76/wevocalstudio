# キーボード操作
キーボードで使用できる操作の一覧。

「ヘルプ」→「ショートカット一覧」で、現在の割り当てを一覧できる。割り当ては、「設定」→「キーとマウス」で変更する。

| 操作 | キー |
| --- | --- |
| 再生と停止 | Space |
| 一時停止 | Ctrl+Space |
| 録音 | Ctrl+R |
| リピート | R |
| 先頭へ、末尾へ | Home、End |
| 編集カーソルを 1 拍移動 | ← → |
| 波形ブロックを 1 拍移動 | テンキーの 4、6 |
| 拡大、縮小 | テンキーの +、-（= と - も使用できる） |
| 全体を表示 | Ctrl+9 |
| 範囲に合わせて拡大 | Ctrl+8 |
| 切り取り、コピー、貼り付け | Ctrl+X、Ctrl+C、Ctrl+V |
| 複製 | Ctrl+D |
| トラックを追加 | Ctrl+T |
| すべて選択 | Ctrl+A |
| 分割 | S |
| 範囲の両端で分割 | Shift+S |
| 削除 | Delete |
| プロパティ | F2 |
| 選択の解除 | Esc |
| 元に戻す、やり直す | Ctrl+Z、Ctrl+Shift+Z（Ctrl+Y） |
| 音量のエンベロープ | E |
| ピッチのエンベロープ | Shift+E |
| スナップ | Alt+S |
| 再生位置に追従 | F |
| マーカーを追加 | M |
| 次、前のマーカー | ]、[ |
| 新しいプロジェクト | Ctrl+N |
| 新しいウィンドウ | Ctrl+Shift+N |
| 開く | Ctrl+O |
| 保存 | Ctrl+S |
| 名前を付けて保存 | Ctrl+Shift+S |
| 音声ファイルを読み込む | Insert |
| 書き出す | Ctrl+Alt+R |

ピッチのキーは、[ピッチと速度](pitch.md#ピッチと速度)を参照する。
